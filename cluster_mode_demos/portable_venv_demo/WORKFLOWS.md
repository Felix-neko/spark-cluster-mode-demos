# 🔄 Workflow диаграммы

## Местный режим (Local Mode)

```
┌─────────────────────────────────────────────────────────┐
│                  LOCAL MACHINE                          │
│  ┌───────────────────────────────────────────────────┐  │
│  │  Python Process                                   │  │
│  │  ┌─────────────────────────────────────────────┐  │  │
│  │  │  main.py                                    │  │  │
│  │  │  - SparkSession (local[*])                  │  │  │
│  │  │  - Driver                                   │  │  │
│  │  │  - Executor 1 (thread)                      │  │  │
│  │  │  - Executor 2 (thread)                      │  │  │
│  │  │  - ...                                      │  │  │
│  │  │                                             │  │  │
│  │  │  ✅ Работает все в одном процессе           │  │  │
│  │  │  ✅ Быстро для разработки                   │  │  │
│  │  │  ✅ Использует все CPU ядра                 │  │  │
│  │  └─────────────────────────────────────────────┘  │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘

Запуск:
$ python main.py

Режим:  LOCAL
```

## Клиентский режим (Client Mode)

```
LOCAL MACHINE                      HADOOP CLUSTER
┌─────────────────────────┐        ┌─────────────────────────┐
│                         │        │                         │
│  main.py                │        │  YARN ResourceManager   │
│  ✓ SparkSession         │        │  ┌───────────────────┐  │
│  ✓ Driver (запущен)     │        │  │  Node Manager 1   │  │
│  ✓ Управляет всем      │◄──────►│  │  ┌─────────────┐  │  │
│  ✓ Следит результатов  │        │  │  │ Executor 1  │  │  │
│  ✓ Обрабатывает данные │        │  │  │ Executor 2  │  │  │
│                         │        │  │  └─────────────┘  │  │
│  stderr/stdout          │        │  └───────────────────┘  │
│  (видны локально)       │        │  ┌───────────────────┐  │
│                         │        │  │  Node Manager 2   │  │
│                         │        │  │  ┌─────────────┐  │  │
│                         │        │  │  │ Executor 3  │  │  │
│                         │        │  │  │ Executor 4  │  │  │
│                         │        │  │  └─────────────┘  │  │
│                         │        │  └───────────────────┘  │
└─────────────────────────┘        └─────────────────────────┘

Запуск:
$ python main.py

Конфигурация:
- master = "yarn"
- deploy_mode = "client"
- spark.pyspark.python = (локальный Python)

Режим:  CLIENT
Логи:   Видны в консоли

Плюсы:
✅ Локальный контроль
✅ Видны логи сразу
✅ Хорош для разработки
✅ Легко дебажить

Минусы:
⚠️  Driver нужно держать включенным
⚠️  Сетевая задержка
```

## Кластерный режим (Cluster Mode)

```
LOCAL MACHINE                      HADOOP CLUSTER
┌─────────────────────────┐        ┌──────────────────────────┐
│                         │        │                          │
│ python submit_cluster.py│        │  YARN ResourceManager    │
│                         │        │                          │
│ 1. Копирует проект      │        │  ┌────────────────────┐  │
│ 2. Создает venv         │        │  │  AppMaster         │  │
│ 3. Архивирует venv      │        │  │  ┌──────────────┐  │  │
│ 4. Загружает HDFS       │◄──────►│  │  │  Driver      │  │  │
│ 5. spark-submit --      │        │  │  │              │  │  │
│    deploy-mode cluster  │        │  │  │ (запущен тут)│  │  │
│                         │        │  │  └──────────────┘  │  │
│ ✓ После запуска         │        │  └────────────────────┘  │
│   можно выключить       │        │                          │
│                         │        │  ┌────────────────────┐  │
│ Логи смотреть на YARN UI│        │  │  NodeManager 1     │  │
│                         │        │  │  ┌──────────────┐  │  │
│                         │        │  │  │ Executor 1   │  │  │
│                         │        │  │  │ Executor 2   │  │  │
│                         │        │  │  └──────────────┘  │  │
│                         │        │  └────────────────────┘  │
│                         │        │  ┌────────────────────┐  │
│                         │        │  │  NodeManager 2     │  │
│                         │        │  │  ┌──────────────┐  │  │
│                         │        │  │  │ Executor 3   │  │  │
│                         │        │  │  └──────────────┘  │  │
│                         │        │  └────────────────────┘  │
└─────────────────────────┘        └──────────────────────────┘

Запуск:
$ python submit_cluster.py

Конфигурация:
- master = "yarn"
- deploy_mode = "cluster"
- archives = "pyspark_env.tar.gz"
- spark.pyspark.python = "./pyspark_env/bin/python"

Режим:  CLUSTER
Логи:   YARN UI (http://yarn-master:8088)

Плюсы:
✅ Production готово
✅ Можно выключить локальную машину
✅ Нет сетевых задержек от Driver
✅ Масштабируется лучше

Минусы:
⚠️  Сложнее дебажить
⚠️  Логи через YARN UI
```

## Submit Cluster Process (Детально)

```
┌──────────────────────────────────────────────────────────┐
│  1. submit_cluster.py запущен локально                   │
│     python submit_cluster.py                             │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  2. Копирование файлов проекта                           │
│     • main.py                                            │
│     • package_dir/                                       │
│     • hadoop_configs/                                    │
│     • requirements.txt                                   │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  3. Выбор метода создания venv                           │
│     ├─ pip (default)                                     │
│     ├─ conda-pack (если --use-conda-pack)               │
│     └─ skip (если --skip-venv)                          │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  4. Создание виртуального окружения                      │
│     $ python -m venv pyspark_env                         │
│     $ pip install -r requirements.txt                    │
│     (создается ~/tmp/pyspark_cluster_prep/pyspark_env)  │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  5. Упаковка в архив                                     │
│     $ tar -czf pyspark_env.tar.gz pyspark_env/           │
│     (результат: ~50-150 MB)                              │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  6. Загрузка на HDFS                                     │
│     $ hdfs dfs -put pyspark_env.tar.gz /user/spark/jobs/ │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  7. Запуск spark-submit                                  │
│     spark-submit \\                                       │
│       --master yarn \\                                    │
│       --deploy-mode cluster \\                           │
│       --archives hdfs:///user/spark/jobs/pyspark_env... \\
│       --conf spark.pyspark.python=./pyspark_env/bin/python \\
│       main.py                                            │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  8. На YARN кластере:                                    │
│     ├─ AppMaster запускает Driver                        │
│     ├─ Driver запускает Executors на NodeManagers        │
│     ├─ pyspark_env.tar.gz распаковывается на каждом     │
│     ├─ main.py выполняется                              │
│     └─ Результаты отправляются в YARN                   │
└──────────────────────────────────────────────────────────┘
                          │
                          ▼
┌──────────────────────────────────────────────────────────┐
│  9. Вывод:                                               │
│     ├─ YARN UI: http://yarn-master:8088                  │
│     ├─ yarn logs -applicationId application_1234567...  │
│     └─ HDFS: /user/spark/jobs/                           │
└──────────────────────────────────────────────────────────┘
```

## Сравнение режимов

```
┌────────────────┬───────────────┬─────────────────┬──────────────┐
│     Аспект     │     LOCAL     │     CLIENT      │   CLUSTER    │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Где работает   │   Локально    │   Driver:       │   Driver:    │
│ Driver         │   все 1 проц. │   локально      │   на кластере│
│                │               │   Executors:    │   на кластере│
│                │               │   на кластере   │              │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Запуск         │ python main.py│ python main.py  │ spark-submit │
│                │               │                 │ или скрипт   │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Логи           │ Консоль       │ Консоль         │ YARN UI      │
│                │ (видны)       │ (видны)         │ (через веб)  │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Использование  │ Разработка    │ Разработка      │ Production   │
│                │ Обучение      │ Интеграция      │ Автоматизация│
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Сложность      │ ⭐            │ ⭐⭐             │ ⭐⭐⭐        │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Масштабируемость│ ⭐            │ ⭐⭐⭐            │ ⭐⭐⭐⭐      │
├────────────────┼───────────────┼─────────────────┼──────────────┤
│ Перформанс     │ ⭐            │ ⭐⭐             │ ⭐⭐⭐        │
└────────────────┴───────────────┴─────────────────┴──────────────┘
```

## Файловая система вовремя cluster submit

```
LOCAL MACHINE                                HDFS CLUSTER
┌──────────────────────────┐         ┌─────────────────────────┐
│                          │         │                         │
│ my_pyspark_project/      │         │ /user/spark/jobs/       │
│ ├── main.py              │ ──────► │ ├── project/            │
│ ├── package_dir/         │ ────┐   │ │   ├── main.py        │
│ ├── requirements.txt      │ ──┐ │   │ │   ├── package_dir/   │
│ └── pyspark_env.tar.gz   │ ──┼─┤   │ │   └── requirements.txt│
│ (создан create_portable) │ ──┤ │   │ │                      │
│                          │   │ └──►│ ├── pyspark_env.tar.gz │
│                          │   │     │ │ (распаковывается на  │
│                          │   │     │ │  каждом executor)    │
│                          │   │     │ │                      │
│                          │   │     │ ├── pyspark_env/       │
│                          │   │     │ │   ├── bin/           │
│                          │   │     │ │   │   ├── python     │
│                          │   │     │ │   │   ├── pip        │
│                          │   │     │ │   │   └── ...         │
│                          │   │     │ │   ├── lib/           │
│                          │   │     │ │   │   └── python3.9/ │
│                          │   │     │ │   └── ...            │
│                          │   │     │ └── application_logs/  │
│                          │   │     │                        │
└──────────────────────────┘   │     └─────────────────────────┘
                               │
                               ▼
                        На каждом Executor:
                        ┌──────────────────┐
                        │ /tmp/yarn/       │
                        │ ├── app.tar.gz   │
                        │ │   (project)    │
                        │ └── pyspark_env/ │
                        │     (работающее) │
                        │                  │
                        │ Запускается:     │
                        │ python           │
                        │   pyspark_env/   │
                        │   bin/python     │
                        │   project/main.py│
                        └──────────────────┘
```

## Выбор метода создания venv

```
                    ┌─────────────────────────┐
                    │ Нужно создать venv?     │
                    └────────────┬────────────┘
                                 │
                    ┌────────────┴────────────┐
                    │ Какой инструмент       │
                    │ вы используете?         │
                    └────┬───────┬───────┬────┘
                         │       │       │
          ┌──────────────┘│       │       └──────┐
          │               │       │               │
          ▼               ▼       ▼               ▼
      ┌────────┐     ┌─────────┐ ┌─────────┐ ┌────────┐
      │ pip    │     │ conda   │ │ UV      │ │ Skip   │
      └────┬───┘     └────┬────┘ └────┬────┘ └────┬───┘
           │              │           │           │
           ▼              ▼           ▼           ▼
      ┌────────┐    ┌──────────────┐ ┌─────────────┐
      │ VENV   │    │ CONDA-PACK   │ │ UV venv     │
      │ method │    │ method       │ │ method      │
      └─┬──────┘    └──────────────┘ └─────────────┘
        │
        └─ Размер: 30-150 MB
           Скорость: средняя
           Надежность: отличная
           Совместимость: везде
```
